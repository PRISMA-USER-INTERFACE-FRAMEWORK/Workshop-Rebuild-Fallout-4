Edit crafting recipes, no FormIDs required

  1. In game, load a save / open a bench once — PrismaCrafting writes the data files.
  2. Click Open skeleton… and pick PrismaCraftingRecipes.skeleton.json
    (in your MO2 overwrite: …\overwrite\Data\PrismaUI_F4\JsonData\).
  3. Optional: Load catalog… → CraftingCatalog.json (same folder) for named perk / global / keyword pickers.
  4. Pick a recipe, edit its components and conditions.
  5. Save config… → save as PrismaCraftingRecipes.json in Documents\My Games\Fallout4\F4SE\. Restart the game to apply.

Only recipes you actually change are written. Everything else stays vanilla.
